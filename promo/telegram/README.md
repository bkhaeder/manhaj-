# حزمة قناة تلكرام لمنصة منهج

- `img/avatar.png`: صورة القناة (1080×1080، تُقص دائرياً في تلكرام).
- `img/*.jpg`: صور المنشورات (1080×1350).
- `kit.json`: الوصف و20 منشوراً مع تواريخها: يومياً من 2026/11/03 إلى 2026/11/22 الساعة 8:30 مساءً بتوقيت بغداد.
- صفحة النشر (فيها أزرار نسخ وعلامة «نُشر» لكل منشور): https://claude.ai/artifact/Qdy9shcY3fWCZpEW9UCWee

## ملاحظات
- **الخطوط:** العناوين بخط Readex Pro، لأن Reem Kufi يرسم حرف «ح» في وسط الكلمة خطاً قصيراً قد يُقرأ خطأ (فتبدو «بحثك» مثل «بثك»). Reem Kufi يبقى لاسم المنصة فقط.
- **إعادة إنتاج الصور:** انسخ `fonts/` و`fonts.css` من `../build`، ثم شغّل `node render.js`.
- **ربط بوت تلكرام:** أُلغي بطلب المالك، فالنشر يدوي عبر جدولة الرسائل في تلكرام.
