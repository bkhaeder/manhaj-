# منصة منهج

منصة يطلب منها الطلبة بحوثاً أكاديمية. الطالب يملأ النموذج، فيصلك إيميل فيه زرّا **موافقة** و**رفض**. عند الموافقة تكتب عدة محركات ذكاء اصطناعي البحث (حتى 20 صفحة)، ثم يُرسل للطالب بنسختين: **Word** و**PDF**.

## كيف تعمل
1. الطالب يدخل بياناته وتفاصيل البحث واللغة وعدد الصفحات (من 5 إلى 20) وإيميله.
2. يصلك إيميل بالطلب فيه زرّا موافقة ورفض، ويصل الطالب إيميل يؤكد استلام طلبه.
3. عند الموافقة:
   - **المحرك الأول** يضع خطة البحث ويكتبه جزءاً جزءاً: الملخص، المقدمة، الفصول، الخاتمة، المراجع.
   - **المحرك الثاني** يراجع المقدمة وكل فصل: يصحح اللغة، ويحذف التكرار، ويعيد صياغة العبارات النمطية.
   - إذا تجاوز محرك حده المجاني أو تعطل، **ينتقل الطلب تلقائياً للمحرك التالي**.
   - يُبنى ملف Word منسق: غلاف، محتويات، ترقيم، كتابة من اليمين لليسار. يُحوَّل الملف إلى PDF، ويُرسل الملفان للطالب، ويصلك إيميل يذكر المحركات المستخدمة.
4. لوحة التحكم `/admin` تعرض الطلبات وحالاتها، وفيها إعادة المحاولة للطلبات الفاشلة.

## المحركات (مجانية)
| المحرك | رابط المفتاح | ملاحظة |
|---|---|---|
| Google Gemini | https://aistudio.google.com/apikey | الأفضل في العربية، ضعه أولاً |
| Groq (Llama) | https://console.groq.com/keys | سريع جداً |
| OpenRouter | https://openrouter.ai/keys | نماذج مجانية متعددة |
| Mistral | https://console.mistral.ai/api-keys | خطة Experiment المجانية |
| Claude | https://platform.claude.com | **مدفوع**، اختياري كاحتياط أخير |

يكفي مفتاح واحد، لكن كلما أضفت مفاتيح أكثر زادت قدرة المنصة اليومية. الترتيب تحدده في `AI_ENGINES`. أسماء النماذج المجانية تتغير أحياناً لدى المزودين، ويمكنك تعديلها من المتغيرات `*_MODEL`.

## النشر المجاني على الإنترنت (Render + Brevo)
1. **الإيميل:** أنشئ حساباً مجانياً في [Brevo](https://www.brevo.com) (يتيح 300 رسالة يومياً). من **Senders** وثّق إيميلك، ومن **SMTP & API → API Keys** أنشئ مفتاحاً.
2. **مفاتيح الذكاء الاصطناعي:** احصل على مفتاح Gemini على الأقل، ويُستحسن Groq أيضاً، من الروابط في الجدول أعلاه.
3. **GitHub:** ارفع مجلد المشروع إلى مستودع جديد على GitHub.
4. **Render:** أنشئ حساباً مجانياً في [Render](https://render.com)، ثم **New → Blueprint** واختر المستودع. سيقرأ Render الملف `render.yaml` ويطلب منك القيم التالية:
   - `ADMIN_EMAIL`: إيميلك، وتصلك عليه الطلبات.
   - `ADMIN_PASSWORD`: كلمة مرور لوحة التحكم.
   - `BREVO_API_KEY` و`MAIL_FROM`: من Brevo، و`MAIL_FROM` هو الإيميل الذي وثّقته.
   - `GEMINI_API_KEY` و`GROQ_API_KEY` وبقية المفاتيح إن وُجدت. اترك فارغاً ما ليس لديك.
5. بعد انتهاء البناء يصبح رابط المنصة مثل `https://manhaj.onrender.com`، وتعمل أزرار الإيميل عليه تلقائياً.
6. **التحقق:** افتح `/admin` (مثلاً `https://manhaj.onrender.com/admin`)، وادخل بأي اسم مستخدم وبكلمة المرور التي اخترتها. اضغط **اختبار المحركات** ثم **إرسال إيميل تجريبي**. إذا ظهرت ✓ أمام كل شيء فالمنصة جاهزة، وأرسل رابطها للطلبة.

> **حدود الخطة المجانية في Render:** تنام المنصة بعد 15 دقيقة بلا زيارات، فيستغرق أول فتح بعدها نحو دقيقة. الملفات لا تُحفظ بعد إعادة التشغيل، لذلك صُممت روابط الموافقة والرفض لتحمل بيانات الطلب موقّعة، فتعمل حتى لو مُسحت قاعدة البيانات. ما يضيع فقط هو سجل لوحة التحكم القديم.

## التشغيل على جهازك
```bash
pip install -r requirements.txt
cp .env.example .env      # املأ القيم
python app.py             # http://localhost:5000
```
لإنشاء PDF محلياً يجب أن يكون LibreOffice مثبتاً على جهازك. داخل Docker يُثبَّت تلقائياً:
```bash
docker build -t manhaj . && docker run -p 10000:10000 --env-file .env manhaj
```

## عن نسبة الاستلال
- النص يُكتب **جديداً** في كل طلب ولا يُنسخ من مصادر. المحركات مُلزمة بالصياغة الذاتية وتوثيق الأفكار بأسلوب APA، والمحرك الثاني يعيد صياغة أي عبارة نمطية. لذلك تكون نسبة التشابه منخفضة عادةً.
- **لا يمكن ضمان 0% في أي أداة فحص:** قائمة المراجع وأسماء المصطلحات والعبارات العلمية الثابتة تطابق دائماً نصوصاً موجودة.
- المنصة لا تحاول إخفاء أن النص مكتوب بالذكاء الاصطناعي عن أدوات كشفه.
- على الطالب مراجعة البحث والتحقق من المراجع وتعديله وفق تعليمات قسمه قبل التسليم.
