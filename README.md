# منصة منهج

منصة يطلب منها الطلبة بحوثاً أكاديمية. الطالب يملأ النموذج، فيصلك إيميل فيه زرّا **موافقة** و**رفض**. عند الموافقة تكتب عدة محركات ذكاء اصطناعي البحث (حتى 20 صفحة)، ثم يُرسل للطالب بنسختين: **Word** و**PDF**.

## ⭐ الطريقة الأسهل: كل شيء داخل حساب Google (مجانية بالكامل)
لا تحتاج GitHub ولا استضافة. المنصة كلها ملف واحد: `google-apps-script/Code.gs`.
1. أنشئ مفتاح Gemini من https://aistudio.google.com/apikey.
2. افتح https://script.google.com واضغط **مشروع جديد**، ثم احذف ما في المحرر والصق محتوى `Code.gs` كاملاً.
3. ضع المفتاح في السطر `GEMINI_API_KEY: ''` بين علامتي التنصيص، ثم احفظ 💾.
4. اختر الدالة **setup** من القائمة أعلى المحرر، واضغط **تشغيل** (Run)، ووافق على الصلاحيات. إذا ظهر تحذير فاضغط **Advanced** ثم **Go to project** ثم **Allow**.
5. اضغط **نشر ← نشر جديد**، واختر النوع **تطبيق ويب**. اجعل «تنفيذ باسم» **أنا**، و«من لديه حق الوصول» **أي شخص**، ثم اضغط **نشر**.
6. رابط **تطبيق الويب** هو رابط منصتك.

- تصلك الطلبات على Gmail مع زرّي الموافقة والرفض.
- جدول «منصة منهج - الطلبات» في Google Drive هو لوحة التحكم، ومجلد «منصة منهج» تُحفظ فيه البحوث.
- **الحدود اليومية المجانية لحساب Google:** نحو 100 إيميل و90 دقيقة من المعالجة الخلفية، أي نحو 15 إلى 20 بحثاً يومياً.

## كيف تعمل
1. الطالب يدخل بياناته وتفاصيل البحث واللغة وعدد الصفحات (من 5 إلى 20) وإيميله.
2. يصلك إيميل بالطلب فيه زرّا موافقة ورفض، ويصل الطالب إيميل يؤكد استلام طلبه.
3. عند الموافقة:
   - **المحرك الأول** يضع خطة البحث ويكتبه جزءاً جزءاً: الملخص، المقدمة، الفصول، الخاتمة، المراجع.
   - **المحرك الثاني** يراجع المقدمة وكل فصل: يصحح اللغة، ويحذف التكرار، ويعيد صياغة العبارات النمطية.
   - إذا تجاوز محرك حده المجاني أو تعطل، **ينتقل الطلب تلقائياً للمحرك التالي**.
   - يُبنى ملف Word منسق: غلاف، محتويات، ترقيم، كتابة من اليمين لليسار. يُحوَّل الملف إلى PDF، ويُرسل الملفان للطالب، ويصلك إيميل يذكر المحركات المستخدمة.
4. لوحة التحكم `/admin` تعرض الطلبات وحالاتها، وفيها إعادة المحاولة للطلبات الفاشلة.

يكفي مفتاح واحد، لكن كلما أضفت مفاتيح أكثر زادت قدرة المنصة اليومية. الترتيب تحدده في `AI_ENGINES`. أسماء النماذج المجانية تتغير أحياناً لدى المزودين، ويمكنك تعديلها من المتغيرات `*_MODEL`.

## النشر المجاني على الإنترنت (Hugging Face Spaces، بلا بطاقة بنكية)
1. **مفتاح Gemini:** من https://aistudio.google.com/apikey اضغط **Create API key** وانسخه.
2. **الإيميل من Gmail:** أنشئ مشروعاً في https://script.google.com والصق فيه `deploy/gmail-relay.gs`، وغيّر قيمة `SECRET`. ثم انشره من **نشر ← نشر جديد ← تطبيق ويب**: «تنفيذ باسم» **أنا**، و«من لديه حق الوصول» **أي شخص**. انسخ الرابط الذي ينتهي بـ `/exec`.
3. **حساب Hugging Face:** سجّل في https://huggingface.co/join.
4. **إنشاء Space:** من https://huggingface.co/new-space اكتب الاسم `manhaj`، واختر **Docker ← Blank**، و**Public**، ثم **Create Space**.
5. **الإعدادات السرية:** في صفحة الـ Space افتح **Settings ← Variables and secrets ← New secret**، وأضف كلاً مما يلي على حدة:
   `ADMIN_EMAIL`، `ADMIN_PASSWORD`، `GEMINI_API_KEY`، `GMAIL_SCRIPT_URL`، `GMAIL_SCRIPT_SECRET`.
6. **ربط GitHub لنقل الكود تلقائياً:**
   - أنشئ مفتاحاً بصلاحية **Write** من https://huggingface.co/settings/tokens.
   - في مستودع GitHub افتح **Settings ← Secrets and variables ← Actions**:
     - في تبويب **Secrets** أضف `HF_TOKEN` وضع فيه المفتاح.
     - في تبويب **Variables** أضف `HF_SPACE` وضع فيه `اسم-مستخدمك-في-huggingface/manhaj`.
   - افتح تبويب **Actions ← Sync to Hugging Face ← Run workflow**.
   - بعد ذلك يُنقل أي تحديث في GitHub إلى المنصة تلقائياً.
7. انتظر حتى تتحول حالة الـ Space إلى **Running** (5 إلى 10 دقائق). رابط منصتك هو `https://اسم-مستخدمك-manhaj.hf.space`.
8. **التحقق:** افتح الرابط وأضف في آخره `/admin`، ثم اضغط **اختبار المحركات** و**إرسال إيميل تجريبي**.

حد Gmail المجاني نحو 100 رسالة يومياً. كل طلب يستهلك 3 أو 4 رسائل، أي نحو 25 طلباً في اليوم.

> **حدود الاستضافة المجانية:** تنام المنصة بعد 48 ساعة بلا زيارات، وتستيقظ تلقائياً عند أول فتح خلال دقيقة تقريباً. الملفات لا تُحفظ بعد إعادة التشغيل، لذلك صُممت روابط الموافقة والرفض لتحمل بيانات الطلب موقّعة، فتعمل حتى لو مُسحت قاعدة البيانات. ما يضيع فقط هو سجل لوحة التحكم القديم.

## التشغيل على جهازك
```bash
pip install -r requirements.txt
cp .env.example .env      # املأ القيم
python app.py             # http://localhost:5000
```
لإنشاء PDF محلياً يجب أن يكون LibreOffice مثبتاً على جهازك. داخل Docker يُثبَّت تلقائياً:
```bash
docker build -t manhaj . && docker run -p 10000:10000 --env-file .env manhaj
```

## عن نسبة الاستلال
- النص يُكتب **جديداً** في كل طلب ولا يُنسخ من مصادر. المحركات مُلزمة بالصياغة الذاتية وتوثيق الأفكار بأسلوب APA، والمحرك الثاني يعيد صياغة أي عبارة نمطية. لذلك تكون نسبة التشابه منخفضة عادةً.
- **لا يمكن ضمان 0% في أي أداة فحص:** قائمة المراجع وأسماء المصطلحات والعبارات العلمية الثابتة تطابق دائماً نصوصاً موجودة.
- المنصة لا تحاول إخفاء أن النص مكتوب بالذكاء الاصطناعي عن أدوات كشفه.
- على الطالب مراجعة البحث والتحقق من المراجع وتعديله وفق تعليمات قسمه قبل التسليم.
